## Short physical tracking diagnostic

`scripts/check_motion_pd.py` resets the physical humanoid to the first frame once, then sends future reference DOFs only as position targets through MimicKit's Isaac Lab engine. It does not force root/body pose during rollout. Default position-control gains, one environment, and 30 Hz control were used; this is not a trained PPO tracker.

| Metric | Start | Stop |
| --- | ---: | ---: |
| Reference length | 2.93 s | 1.93 s |
| Time until MimicKit FAIL | 1.27 s | 1.23 s |
| Root position error, mean / max | 0.165 / 0.637 m | 0.281 / 0.695 m |
| Mean joint target error | 0.039 rad | 0.066 rad |
| Max body position error at failure | 1.018 m | 1.115 m |
| Unexpected ground contact at failure | none | none |
| Root height at failure | 0.748 m | 0.361 m |

Both failed the environment's 1.0 m pose-error criterion before the clip ended. The stop motion also dropped low. This establishes that these clips are **not yet demonstrated physically trackable with the default PD controller**; it does not prove a learned tracker could never execute them. No PPO training or physics-validity claim should be made from forced-pose playback.

## 2026-09-28 follow-up: separate controller limits from reference quality

The same position-target PD diagnostic also failed on MimicKit's own `humanoid_walk.pkl`: 0.57 s of a 1.03 s clip, with ~1.00 m maximum body position error. Thus PD failure alone is **not evidence that the retargeted clips are physically impossible**. It is an open-loop reference-joint controller without a learned balance policy; its small joint target error can coexist with severe whole-body balance error.

At termination, the original retargets had no unexpected ground contacts, but the physical root was tilted about 47° for start and 68° for stop. Both hit MimicKit's 1.0 m body pose-error failure threshold; the stop root fell to 0.36 m. This points to lost balance/body tracking under this controller, rather than a joint-command parsing failure. A generic humanoid PPO tracker has not yet been trained for these references.

A separate `xyfix` candidate was generated by holding the ankle's horizontal target fixed during contact while easing foot orientation and height. Contact-labeled ankle XY speed (95th percentile) fell from 0.274 to <0.001 m/s for start and from 0.130 to <0.001 m/s for stop. Joint limit violations remain zero. However, the start clip's maximum root-height jump rose from 17.5 to 31.6 mm, and the PD failure times did not improve (start 1.27 s, stop 1.23 s). Therefore the default viewer settings still point to `temporalfix`; `xyfix` is a diagnostic candidate, not an accepted replacement. Further work should improve the foot/height tradeoff and evaluate with a trained common tracker.
